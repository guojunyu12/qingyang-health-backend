# M02 体验优化记录

日期：2026-10-19。范围仅限 M02，公共接口、冻结 SQL、其他业务模块和根依赖未修改。

- 健康档案：必填目标集中展示，可选身体信息和营养目标收纳为可展开区域；保持完整 PUT、空值与版本冲突规则。
- 饮水/体重：复用独立记录面板，直接选择过去 30 天的日期与时间；今天可用服务端保存时刻，也可录入指定时间；保存前预览上海日期归属。
- 饮水快捷量：手动表单提供 100/250/500 ml，首页快捷杯仍为 250 ml。杯形进度按用户设置的目标计算。
- 删除记录：先展示日期、时间和记录值，再由用户明确确认；取消不发删除请求。饮水说明删除不恢复积分资格。
- 看板：历史日期增加“返回今天”入口；体重入口在原中等窗口断点仍可见；窄屏保留目标文字。
- 大屏：体重测量点支持点击与键盘选择；饮水图按日期选择数值，30 天日期标签按周简化；未知/缺测仍明确显示，不造数、不连缺测点。
- 弹层：取消和 Escape 关闭后将焦点恢复到原入口。

验证：现有 20 项测试通过；类型检查通过。浏览器实际检查了补录选择与预览、删除确认后取消保留测量、档案折叠、图表日期选择、窄窗口页面无整体横向溢出，以及体重弹层 Escape 的焦点恢复。检查未新增或删除现有测试账号的健康事实。

已更新专用 Playwright 脚本的删除确认步骤和中等窗口断点；本轮未自动重跑完整浏览器脚本，以实际页面交互检查验证本轮功能。原交付单的 11 组 MySQL 验收与前一版完整浏览器流程结果保留为历史结果；后端及数据库本轮无变更。
